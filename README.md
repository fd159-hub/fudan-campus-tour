# 復旦國小沉浸式校園導覽

Three.js校園白模0.3公開測試版。

網站：https://fd159-hub.github.io/fudan-campus-tour/

支援電腦、手機與平板，可旋轉、縮放、切換建築與樓層、搜尋教室及定位。

公開內容僅為建構完成的模型、場域名稱與網站程式。原始Word、PDF、消防圖PNG、配置圖、內部核對資料及原圖對照功能均未公開。

模型為示意：1F～4F主體外框、主要走廊與禮堂挑空已分層整理；樓梯只標位置，非實際階數或可通行路徑。樓高、地下室深度、詳細門位與室外配置仍待核對。尚未測試實體手機與iPad效能。

無需編譯，以任一靜態HTTP伺服器即可預覽。Three.js 0.180.0已存於vendor，授權見vendor/THREE-LICENSE.txt。
