# 復旦國小沉浸式校園導覽

Three.js校園導覽0.7公開測試版。

網站：https://fd159-hub.github.io/fudan-campus-tour/

支援電腦、手機與平板，可旋轉、縮放、切換建築與樓層、搜尋教室及定位。

點選「開始六站導覽」，依序認識全校總覽、行政處室、低年級教室、創客教室、圖書館與禮堂。支援上一站、下一站、直接選站、方向鍵及ESC結束；完成或結束後還原進入前的視角與篩選。這是場域鏡頭導覽，不是已確認的步行路線或第一人稱漫遊。

「校園地面漫遊」提供室外地面視角：WASD移動、拖曳轉頭、方向鍵前後與轉頭、Shift快步、ESC結束；手機按住方向按鈕移動。簡圖標示位置，可回到起點。室內與上下樓尚未開放，碰撞依建構模型主體外框保守阻擋，不代表現場可通行路徑。

0.7 建立四面圍牆與南、東、西側約 1.5 公尺寬的人行道。地面漫遊可從大門外向東或向西繞行。北側未拍攝的牆段依相鄰樣式補建，圍牆位置及尺寸為模型估算。

公開內容僅為建構完成的模型、場域名稱與網站程式。原始Word、PDF、消防圖PNG、配置圖、內部核對資料及原圖對照功能均未公開。

模型為示意：1F～4F主體外框、主要走廊與禮堂挑空已分層整理；樓梯只標位置，非實際階數或可通行路徑。樓高、地下室深度、詳細門位與室外配置仍待核對。尚未測試實體手機與iPad效能。

無需編譯，以任一靜態HTTP伺服器即可預覽。Three.js 0.180.0已存於vendor，授權見vendor/THREE-LICENSE.txt。
